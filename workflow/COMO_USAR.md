# Como usar (você)

1. Abra o Antigravity nesta pasta do projeto (Portfolio_Interativo).
2. Cole no agente: 
   "Leia workflow/PROTOCOL.md e execute a rodada normal para todos os itens de workflow/queue.json."
3. Quando ele terminar, volte aqui e diga ao Claude: "audita".
4. O Claude escreve workflow/feedback.json (approved / redo + prompt corrigido).
5. Cole no Antigravity: 
   "Leia workflow/PROTOCOL.md e execute a rodada de refação."
6. Repita 3-5 até tudo aprovado. O Claude move os aprovados para app/public/... e converte para webp.
